# 3. The catalogue of story types

Generated by `tools/story/make_story_types.py` from the same tables as `story_types.json`. **76 story types** in 7 families, built on 10 beat templates. Coverage, checked by the script:

- **Polti's 36 situations:** all mapped. #15, #18, #19 and #26 are rare, off-screen backstory only; #16 is recast as crisis and recovery. #31 (conflict with a god) is left to the literary phase.
- **Booker's 7 plots** and **Tobias's 20 master plots**: all mapped.
- **Frye's 4 mythoi** are the outcome families; the **Reagan shapes** are the emotional curves.
- **Regis's 8 elements** make up the courtship template, and **kishōtenketsu** the quiet template.

## Beat templates
- **freytag**: setup → incite → complicate → confront → turn → last_chance → resolve
- **romance**: society → meeting → barrier → attraction → declaration → ritual_death → recognition → commitment
- **kisho**: ki → sho → ten → ketsu
- **revenge**: wrong → learning → vow → pursuit → reckoning → aftermath → settle
- **mystery**: anomaly → question → inquiry → false_lead → recognition → exposure → restore
- **rebirth**: shadow → respite → relapse → depth → redemption
- **journey**: call → refusal → mentor → threshold → trials → ordeal → reward → return
- **reconcile**: rift → distance → reminder → approach → setback → recognition → reunion
- **tragedy**: anticipation → dream → frustration → nightmare → destruction
- **monster**: shadow → gathering → frustration → nightmare → deliverance
